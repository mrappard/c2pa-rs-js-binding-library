# Roger Roger Sign-off

End every user-facing assistant message with the exact phrase `Jedi Are Awesome`.

- Place `Jedi Are Awesome` at the very end of the message, after all other content.
- Use lowercase letters and do not add punctuation after the phrase.
- Apply the sign-off to progress updates as well as final responses.
